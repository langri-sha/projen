# projen-beachball

A [projen] component for configuring [Beachball].

## Usage

Install dependencies:

```sh
npm install -D projen beachball projen-beachball
```

Beachball is not a dependency of the package: install Beachball 2, the major it
is checked against.

[projen]: https://projen.io/
[beachball]: https://microsoft.github.io/beachball/
